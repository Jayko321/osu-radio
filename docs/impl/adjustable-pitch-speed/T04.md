# T04. Автономный QML-компонент меню модов

Состояние: реализовано; целевой offline probe и QML lint пройдены. Общий Qt-набор имеет отдельный сбой artwork, воспроизведённый на старом release.
Источники: [спецификация](../../specs/adjustable-pitch-speed.md), R1, R2, R6–R8;
[решение UI](../adjustable-pitch-speed.md#время-интерфейс-и-интеграции).
Зависимости: нет. Независима от T01, T02, T03.

## Результат

Готов переиспользуемый popup, проверяемый в offline Qt probe: DT/HT/NC,
скорость, Adjust pitch, снятие модов, saving/error/Retry и клавиатурный фокус.
Он отображает переданное состояние и выдаёт намерения пользователя.
Живое подключение и показ в галерее — T09.

## Границы и контекст

- Владение: новый компонент под `apps/osu-radio-qt/qml/components/`,
  нужные записи `components/qmldir` и его offline-пробы в
  `tests/AdapterProbe.qml`, `tests/launch_smoke.rs`.
  `build.rs` рекурсивно регистрирует QML: проверить регистрацию,
  не добавлять ручной список файлов без необходимости.
- Читать GUI skill и соседние AppMenu/AppSwitch/IconButton/Theme,
  существующий volume popup в `qml/PlayerPanel.qml`.
  PlayerPanel/Main/SettingsPanel/Gallery, Rust-адаптеры и client mock
  здесь не менять — они принадлежат T09/T06.
- Дать компоненту входы для режима/скорости/pitch, доступности, состояния
  сохранения/ошибки; выходы для действий DT-cycle, HT-toggle, speed,
  pitch, clear и Retry. Имена конкретизировать локально и записать для T09.
  D/E и мышь выдают одинаковые намерения. Цикл и defaults вычисляет клиент,
  не дублировать бизнес-правила в QML.
- Клавиши D/E ловить внутри открытого меню; Escape/outside dismiss и
  восстановление фокуса сохранить. F1 маршрутизирует shell в T09.
  Нужны доступные имена, достижимые контролы и размеры при 1024×640.
- В тестовом harness передавать состояния явно и проверять сигналы;
  не создавать второй mock/backend или временную продуктовую модель.
  Факты и ссылки для frontend guide передать T11.

## Проверка и приёмка

Проверить отображение none, DT, NC 1.20, HT; шаг/границы slider по входному
режиму, disabled control, saving/error/Retry. Клавиши D/E в открытом popup
выдают по одному нужному intent, вне него не действуют; mouse и keyboard
достигают тех же сигналов. Escape/Tab/Shift+Tab и закрытие не оставляют
скрытому контролу клавиатурный фокус.

После сборки Qt выполнить целевой offline probe и
`bash apps/osu-radio-qt/scripts/lint-qml.sh`; необходимые Qt тесты запускать
последовательно с `--test-threads=1`. Существующая инфраструктура —
`cargo test -p osu-radio-qt --locked -- --test-threads=1`.
Не добавлять вторую матрицу сохранения/режимов вместо T06.
Связь с AppController, реальный ввод, аудио и Windows остаются T09/T12.

## Отчёт о выполнении

Реализация от 2026-10-20. Пользовательская приёмка не проводилась.

### Изменённые файлы и контракт для T09

- `apps/osu-radio-qt/qml/components/AudioModsPopup.qml` — автономный
  `Basic.Popup`, стили и кнопки проекта, native Slider и AppSwitch.
- `apps/osu-radio-qt/tests/AdapterProbe.qml` — fixture с явно переданными
  состояниями и записью сигналов; сценарий `controls-mods`.
- `apps/osu-radio-qt/tests/launch_smoke.rs` —
  `offline_mods_popup_renders_state_and_emits_mouse_and_keyboard_intents`.
  Запуск через offline gallery, backend запрещён; проверяется отсутствие
  старта сервера и SQLite в временной папке.
- Эта карточка и строка T04 общего плана — фактическое состояние и передача.

Входы `AudioModsPopup`:

| Свойство | Назначение |
| --- | --- |
| `mode: string` | `none`, `dt`, `ht`; `dt` + `adjustPitch` отображается как NC. |
| `speedPercent: int` | Переданная скорость в целых процентах; подпись показывает множитель с двумя знаками. |
| `adjustPitch: bool` | Состояние Adjust pitch. |
| `available: bool` | Доступность редактирования; закрыть popup можно и при `false`. |
| `saving: bool` | Показывает Saving… и блокирует Retry; дальнейшее редактирование разрешено. |
| `errorMessage: string` | Текст ошибки с переносом строк; при ошибке показывается Retry. |
| `canRetry: bool` | Разрешение Retry от владельца состояния, независимо от доступности редактирования. |

Выходы: `dtCycleRequested()`, `htToggleRequested()`,
`speedRequested(int percent)`, `pitchRequested(bool adjust)`,
`clearRequested()`, `retryRequested()`.
Кнопки DT/NC и HT и клавиши D/E выдают одинаковые сигналы. Скорость slider
ограничена переданным режимом: DT 101–200, HT 50–99, шаг 1 процент;
для none скорость/pitch/clear выключены. Ни цикл, ни defaults, ни сохранение
в QML не вычисляются. NC не вводит отдельный режим.

T09 задаёт `parent`/координаты popup около кнопки и связывает входы/сигналы
с клиентом. F1 маршрутизирует shell. Закрытие при смене адресата и отклонение
поздних действий остаются обязательствами T09/T06. Popup сам обрабатывает
D/E только открытым, игнорирует auto-repeat и Ctrl/Alt/Meta-модификаторы,
закрывается по Escape/outside/кнопке и восстанавливает записанный перед
открытием фокус.

`build.rs` уже рекурсивно регистрирует `.qml`. После сборки в generated
`OsuRadio/qmldir` подтверждена строка
`AudioModsPopup 1.0 qml/components/AudioModsPopup.qml`; прямой import
`components` использует файл автоматически. Изменения source qmldir и
ручные списки ресурсов не нужны. Живые панели, Gallery, Rust-адаптеры,
клиент/mock не менялись этой карточкой.

их файлы сохранены. Для Cargo использованы только переменные окружения:

```sh
LIBCLANG_PATH=/opt/rocm/lib/llvm/lib
```

проекта и зависимости в T04 не менялись.
