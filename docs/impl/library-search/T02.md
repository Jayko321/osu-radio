# T02. Stars и статусы из osu!stable

Состояние: реализовано и проверено; пользовательская приёмка не проводилась.
Источники: [спецификация](../../specs/library-search.md), R6–R8, R11–R12;
[план](../library-search.md), раздел 2 «Импорт stable» и раздел 5.
Зависимости: T01 — nullable импортные поля и их запись в снимок.

## Результат

Stable reader сохраняет no-mod stars исходного игрового режима и приводит
статус к общему смыслу. Отсутствующий рейтинг и ranked/submitted остаются
неизвестными. Источник читается без изменений.

## Границы и контекст

Использовать [scanner-процедуру](../../../.agents/skills/osu-radio-scanner/SKILL.md).
После T01 сверить фактические импортные типы и статусы в
[import_types.rs](../../../crates/radio-core/src/import_types.rs).

- В [Reader::beatmap](../../../crates/radio-scanner/src/stable/reader.rs)
  перестать пропускать статус, mods/stars и mode. Режим встречается после таблиц:
  выбрать `mods=0` именно из таблицы исходного режима. Не использовать первую
  таблицу или первую запись с модами. Нет таблицы/записи — нет рейтинга.
- Сохранить все поддержанные layouts: до `20140609` таблиц stars нет;
  tags `0x0c`/`0x0d` определяют float/double; оба формата `20191106`
  требуют полной проверки записи и footer. Не ослаблять проверки длины,
  типов, усечённого ввода и отказ от частичного результата.
- Нормализация статусов: 4 → ranked, 5 → approved, 6 → qualified, 7 → loved,
  2 → pending; 0/1/3 и неизвестные коды → none. Рядом добавить согласованный
  `shortcut:` о неразличимости pending/wip/graveyard для кода 2 и пересмотре
  при изменении/удалении поддержки stable.
- Протянуть значения через [stable/mod.rs](../../../crates/radio-scanner/src/stable/mod.rs).
  Сохранить группировку папок, порядок, BPM, MD5, media paths, collections
  и импорт `osu_last_played_at_ms`. Существующий `count_beatmaps` должен
  по-прежнему полностью валидировать тот же формат.
- Ranked/submitted не получать из даты файла, локального создания или импорта;
  не добавлять сетевые запросы и пересчёт stars. Scanner не определяет
  длительность аудио: это T04 в services.
- Расширить текущие binary fixtures в
  [stable/tests.rs](../../../crates/radio-scanner/src/stable/tests.rs);
  обновить [scanner guide](../../agent/scanner.md) с временным ограничением stable.

## Проверка и приёмка

Проверять source mapping здесь, а семантику поисковых сравнений — в T06/T07.

- Разные stars по четырём режимам и mods доказывают выбор исходного режима
  и `mods=0`; отсутствие no-mod записи не превращается в 0 или чужой рейтинг.
- Float/double и старый layout без stars дают ожидаемые значения/отсутствие.
  Все коды статусов отображаются по таблице выше; обе даты остаются неизвестными.
- Повреждённые star tags, counts и усечённая запись дают ошибку без частичного
  снимка. Прежние проверки группировки и last played продолжают проходить;
  источник до/после импорта не изменён.

```sh
cargo test -p radio-scanner --locked stable::
```

Команда использует существующие временные источники с явными путями.
Нужны prerequisites сборки scanner/helper из
[development guide](../../agent/development.md#platforms-and-prerequisites).
Не запускать неограниченное discovery. Проверка синтетического `osu!.db`
не означает проверку пользовательской установки или всех Windows paths.

## Отчёт о выполнении

Изменены `stable/reader.rs`, `stable/tests.rs` и `docs/agent/scanner.md`;
существующий mapping `stable/mod.rs` передаёт готовый `ImportedBeatmap`, даты
набора остаются `None`. Код читает все таблицы и выбирает no-mod по mode;
тесты `maps_stars_and_status_from_stable` и `imports_stars_without_changing_source_or_inventing_dates`
проверяют выбор, статусы, даты и неизменность файла. Существующие тесты
проверяют layouts, ошибки, группировку, collections и last played.

`cargo test -p radio-scanner --locked stable::` — 23 passed. Первая попытка
выявила устаревший поиск байтов в тесте повреждённого count после изменения
фикстуры; он исправлен, повторный запуск прошёл. Реальная установка и Windows
paths не проверялись; пользовательская приёмка не проводилась. Расхождений
с карточкой не обнаружено.
