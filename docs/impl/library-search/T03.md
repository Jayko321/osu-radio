# T03. Stars, статусы и даты из osu!lazer

Состояние: реализовано и проверено; пользовательская приёмка не проводилась.
Источники: [спецификация](../../specs/library-search.md), R6–R9, R11–R12;
[план](../library-search.md), раздел 2 «Импорт lazer» и раздел 5.
Зависимости: T01 — импортные поля и сохранение новых значений.

## Результат

Реальный Realm helper, NDJSON decoder и импортные типы согласованно передают
stars/status сложности и ranked/submitted набора. Старые/неполные источники
без этих свойств остаются читаемыми с неизвестными значениями.

## Границы и контекст

Использовать [scanner-процедуру](../../../.agents/skills/osu-radio-scanner/SKILL.md).
Сверить типы после T01 и принятую нормализацию статусов; исходные числовые
коды lazer нельзя интерпретировать как коды stable.

- В [Program.cs](../../../tools/osu-lazer-realm-parser/Program.cs),
  `ExportBeatmapSets`/`ToBeatmap`, добавить извлечение
  `Beatmap.StarRating`, `Beatmap.Status`, `BeatmapSet.DateSubmitted`,
  `BeatmapSet.DateRanked`. Переиспользовать optional-field helpers и
  `GetUnixMilliseconds`; даты сохранять в UTC milliseconds.
- Согласованно обновить `LazerBeatmapSetRecord`, `LazerBeatmapRecord`
  и преобразования в [lazer/types.rs](../../../crates/radio-scanner/src/lazer/types.rs).
  Отсутствующие свойства, nullable значения и stars sentinel `-1` означают
  неизвестное значение, а не ноль. Нормализацию статуса выполнять по смыслу
  enum закреплённой в плане ревизии, включая none.
- Сохранённые stars относятся к исходному режиму без модов; не добавлять
  перерасчёт, сетевое обогащение или отдельную семантику UserTags.
  Сохранить `LastPlayed`, MD5, метаданные, файлы и collections.
- Сохранить read-only открытие Realm, NDJSON в stdout, diagnostics в stderr,
  обработку повреждённых записей и ошибок helper. Не менять выбор executable.
- Расширить существующий
  [fixture-generator](../../../tools/osu-lazer-realm-parser/fixture-generator/Program.cs)
  и [lazer tests](../../../crates/radio-scanner/src/lazer/tests.rs).
  Обновить [helper README](../../../tools/osu-lazer-realm-parser/README.md)
  и [scanner guide](../../agent/scanner.md); сохранить правки T02, если она уже выполнена.

## Проверка и приёмка

Риск находится на стыке динамической Realm-схемы, C#-вывода и Rust DTO:
одного JSON-примера недостаточно.

1. Минимальная Realm-фикстура без новых свойств импортируется; значения остаются
   неизвестными. Rich fixture содержит известные stars, статусы и обе даты;
   они доходят до `ImportedSnapshot` без подмены source-кодов или единиц времени.
2. Отдельные значения sentinel/unknown и сохранённая дата игры не смешиваются
   с новыми датами; отсутствующие даты не берутся из локальных временных полей.
   Набор значений fixture должен отличать таблицы кодов stable и lazer.
3. В существующем real-helper round-trip проверить новые поля и неизменность
   байтов исходной Realm. Сохранить проверки ошибок, stdout/stderr и NDJSON;
   fixtures генерировать во временном каталоге.

```sh
dotnet build tools/osu-lazer-realm-parser/osu-lazer-realm-parser.csproj --configuration Release --nologo
cargo test -p radio-scanner --locked lazer:: -- --test-threads=1
```

Вторая команда включает текущие `real_*` тесты модуля; убедиться по результату,
что они запускались с настоящим собранным helper. Подмена его на `/bin/false`
не подтверждает эту карточку. Нужны .NET/Realm prerequisites; пользовательскую
Realm не открывать для записи. Проверка временных Realm не подтверждает все
ревизии установленного lazer или нативное выполнение Windows.

## Отчёт о выполнении

Изменены `Program.cs` helper и fixture-generator, `lazer/types.rs`,
`lazer/tests.rs`, README helper и scanner guide. NDJSON передаёт `stars`,
числовой lazer `status`, `ranked_at_ms`, `submitted_at_ms`; Rust нормализует
статусы по закреплённому enum и sentinel -1. Минимальная Realm без свойств,
rich Realm со значениями, nullable/sentinel/unknown, LastPlayed и неизменность
байтов проверяются настоящим helper в `imports_real_realm_fixtures_with_the_production_helper`
и `real_realm_metadata_and_file_references_round_trip_without_modifying_the_database`;
все коды enum проверяет `maps_lazer_status_codes_and_unknown_stars`.

- `dotnet build ... --configuration Release --nologo` — успешно; NU1900:
  недоступны данные NuGet vulnerability audit; также предупреждение Realm о
  пустой default schema динамического helper.
- `cargo test -p radio-scanner --locked lazer:: -- --test-threads=1` с явным
  путём к собранному production helper — 25 passed, 1 failed: fake-helper тест
  отмены не дождался исчезновения PID в песочнице. Все real-helper тесты прошли.
- Этот тест отдельно вне PID-изоляции — passed. Поведение импорта проверено на
  синтетических Realm, не на пользовательской установке или Windows. Пользовательская
  приёмка не проводилась. Других расхождений не обнаружено.
