## Проверка и приёмка

- `lint-qml.sh`; `cargo test -p osu-radio-qt --locked --test launch_smoke -- offline_ gallery_ --test-threads=1`.
- Пробы меню проверяют клавиатурную навигацию, значения ролей и фокус.
  Добавить в пробу `controls-popups` утверждения: у `AppMenu` popup `dim === false`
  и `modal === true`; у пункта с `destructive` цвет текста `Theme.red`.
- Ошибочный случай: клавиатурное закрытие по Escape возвращает фокус на строку;
  пункт с `enabled: false` не активируется.
- Не проверено без пользователя: вид тени и размытия (GPU). Пользователь
  проверяет в приложении ПКМ по треку, ⋮ у плейлиста, сортировку.

## Отчёт о выполнении

Изменённые файлы (`apps/osu-radio-qt`):

- Новые: `qml/components/AppMenuItem.qml`, `AppContextMenu.qml`, `PopupSurface.qml`.
- `TrackQueueMenu.qml`: собран на `AppContextMenu` и `AppMenuItem`, публичный API и
  `objectName` сохранены, «Remove from playlist» стал `destructive`.
- `PlaylistPane.qml`: меню `actions` на `AppContextMenu`; локальный `ActionItem` теперь
  `AppMenuItem` с прежним `enabled: root.connected && !root.busy`; «Delete» `destructive`.
- `AppMenu.qml`: `dim: false` (при `modal: true`), фон `PopupSurface`.
- `PlayerPanel.qml` (громкость, рамка `Theme.muted` и радиус 8 сохранены) и
  `AudioModsPopup.qml`: фон `PopupSurface`. `AppModal` не менялся.
- `tests/AdapterProbe.qml`: ожидание ширины меню плейлиста 236 → 252 (по карточке); в
  `controls-popups` добавлены проверки `dim === false` и `modal === true` у `AppMenu`,
  фокуса на первом доступном пункте, цвета `Theme.red` у `destructive`, неактивного
  пункта (клик не срабатывает), Escape (фокус на исходный элемент), Down+Return
  (срабатывает нужный пункт, фокус возвращается).
- `docs/agent/frontend.md`: абзац о меню вставки дополнен новыми компонентами.

Решения: `PopupSurface` — общий фон на четыре места (меню, список, громкость, Mods);
тень через `layer.effect: MultiEffect` (`shadowEnabled`, по документации Qt 6.8).
Возврат фокуса в `AppContextMenu` берёт активный элемент окна при `aboutToShow`; для
`TrackQueueMenu` это строка (её фокусирует `openAt`), для карточки плейлиста — кнопка ⋮ или
карточка, как раньше.
