# T17. Окно выбора папок

Состояние: выполнено; вид капсул и ширина на минимальном окне не проверены.
Источники: [план](../ui-refresh.md), решения 17, 19; [предпросмотр](preview.html), переключатель «Окно папок».
Зависимости: T01, T02 (иконка `rotate-cw`, `plus`, `minus` уже есть).

## Результат

Состояние каждой строки названо словами, ссылка без адреса убрана, подписи английские.
Цвета бейджей STABLE и LAZER не меняются.

## Границы и контекст

Перед началом прочитать [AGENTS.md](../../../AGENTS.md),
[docs/agent/frontend.md](../../agent/frontend.md) (описание папок и импорта) и
разделы «Общие правила» и «Общие проверки» [плана](../ui-refresh.md).

Файл: `components/FolderSelectionModal.qml`, `Gallery.qml`. Сейчас: действие строки
(`modelData.action`: `add`, `remove`, `refresh`) видно только цветом рамки; кнопка
«Need help?» открывает `https://www.google.com`; подпись и подсказка кнопки
обновления на русском («Обновить импорт»); подсветка нажатых кнопок литералом
`#409c7ef8`. Логика выбора и применения (`toggleRequested`, `refreshRequested`,
`applyRequested`, `computingFrame`) не меняется.

Сделать:

1. В строке рядом со счётчиком: капсула состояния, когда `action` задано:
   `add` «Will be added» (иконка check), `remove` «Will be removed» (иконка minus,
   красноватая), `refresh` «Will be refreshed» (иконка `rotate-cw`). Цвета капсул:
   акцентный полупрозрачный для add и refresh, красный полупрозрачный для remove;
   текст в тон. Рамка строки остаётся вторым признаком. Капсула не должна
   вытеснять путь и счётчик на узкой модалке (элементы переносятся или сжимаются).
2. Удалить кнопку «Need help?» целиком: пока нет настоящего адреса.
3. Подпись `accessibleName` и подсказка кнопки обновления: «Refresh import».
   Обновить `AdapterProbe.qml` (проверка `refresh.accessibleName` около
   строки 1232).
4. Подсветку нажатых кнопок заменить на `Theme.accentSoft` из T01 (литерал
   `#409c7ef8` исчезает).
5. **Не менять** цвета `#f573ad` и `#39d5d5` (бейджи типа) и цвета фона строк:
   пользователь отклонил любые правки контраста.
