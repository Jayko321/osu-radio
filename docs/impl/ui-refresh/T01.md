# T01. Токены темы

Состояние: выполнено; один `launch_smoke` падал и до карточки (см. отчёт).
Источники: [план](../ui-refresh.md), решения 1, 19; [предпросмотр](preview.html).
Зависимости: нет.

## Результат

`Theme.qml` содержит общие токены, а повторяющиеся литералы цветов в QML заменены
ссылками на них. Внешний вид не меняется: цвета и размеры идентичны прежним.

## Границы и контекст

Перед началом прочитать [AGENTS.md](../../../AGENTS.md),
[docs/agent/frontend.md](../../agent/frontend.md),
[процедуру GUI](../../../.agents/skills/osu-radio-gui/SKILL.md) и разделы «Общие правила» и
«Общие проверки» [плана](../ui-refresh.md).

Файл: `apps/osu-radio-qt/qml/components/Theme.qml` (синглтон, уже регистрируется
`build.rs` по имени файла). Сейчас в нём: `background #0e0e0e`, `text #eff1f5`,
`muted #767982`, `accent #9366ed`, `surface #3384898f`, `border #1af2f4fc`,
`red`, `green`, `fontFamily`.

Добавить свойства (ARGB, как в остальном Theme):

- `hover: "#14f2f4fc"`; `popup: "#f20d0d0d"`; `modal: "#f218181b"`;
  `accentSoft: "#409366ed"`.
- Длительности в мс: `motionQuick: 80`, `motionFast: 120`, `motionBase: 160`,
  `motionPanel: 200`, `motionSlow: 250`.
- `easing: Easing.OutCubic`; `motion: true` (внутренний флаг без настройки в UI);
  `function ms(value)` возвращает `motion ? value : 0`. Последующие карточки
  оборачивают в него все длительности.

Заменить литералы на токены, ничего больше не меняя:

- `#14f2f4fc` → `Theme.hover`: `IconButton.qml`, `TrackQueueMenu.qml`,
  `PlaylistPane.qml`, `WindowBar.qml` (два места).
- `#f20d0d0d` → `Theme.popup`: `AppMenu.qml`, `AudioModsPopup.qml`,
  `PlayerPanel.qml` (фон попапа громкости), `MaterialSurface.qml` (вид `thick`).
- `#f218181b` → `Theme.modal`: `AppModal.qml`.

Не трогать в этой карточке: `#161616` и `#333333` (T03), `#c142b0` (T13),
`#69c9ff` (T08), `#409c7ef8` (T17), градиенты карточек, цвета бейджей папок.
`Gallery.qml` не менять без необходимости.

## Проверка и приёмка

- `rg '"#14f2f4fc"|"#f20d0d0d"|"#f218181b"' apps/osu-radio-qt/qml` находит
  только `Theme.qml` (и `Gallery.qml`, если он содержит литералы; их тоже заменить).
- `apps/osu-radio-qt/scripts/lint-qml.sh` проходит.
- `cargo test -p osu-radio-qt --locked -- --test-threads=1` проходит, включая
  проверку шрифтов и ресурсов `native-assets`.
- Визуально ничего не меняется: ручная проверка не требуется.

## Отчёт о выполнении

Изменённые файлы (все в `apps/osu-radio-qt/qml/`): `components/Theme.qml` (токены
`hover`, `popup`, `modal`, `accentSoft`, `motionQuick/Fast/Base/Panel/Slow`, `easing`,
`motion`, `ms()`); литералы заменены в `components/IconButton.qml`,
`TrackQueueMenu.qml`, `PlaylistPane.qml`, `AppMenu.qml`, `AudioModsPopup.qml`,
`MaterialSurface.qml`, `AppModal.qml`, `PlayerPanel.qml`, `WindowBar.qml` (два места).
`Gallery.qml` литералов не содержал и не менялся.

Проверки:

- `rg '"#14f2f4fc"|"#f20d0d0d"|"#f218181b"' apps/osu-radio-qt/qml` — только `Theme.qml`.
- `cargo build -p osu-radio-qt --locked` — успешно.
- `apps/osu-radio-qt/scripts/lint-qml.sh` — код выхода 0.
- `cargo test -p osu-radio-qt --locked -- --test-threads=1` — 31 пройдено, 1 не пройден,
  3 пропущено (ignored); тесты шрифтов и ресурсов прошли.

Расхождение: `launch_smoke::warmed_navigation_fast_scrolling_and_cache_pressure_keep_displayed_artwork_ready`
падает с «VISUAL ISSUE: background/player image loses readiness/source» (134 замечания).
На исходном коде (изменения QML убраны через `git stash`) тест падает так же (188
замечаний), то есть падение существовало до карточки и с цветами не связано. Причина
не исследовалась.

Не проверено: остальные команды раздела «Общие проверки» (клиентские тесты, Python-тесты,
Clippy, `cargo fmt`) не запускались, так как карточка не трогает Rust-код; визуальная
сверка не выполнялась (по карточке не требуется). Токены `accentSoft`, `motion*`, `easing`,
`ms()` пока нигде не используются — их подключают следующие карточки.
`tests/AdapterProbe.qml` содержит литерал `#f20d0d0d` как независимое ожидание цвета
`thick`, оставлен без изменений.
