# T02. Новые иконки

Состояние: выполнено.
Источники: [план](../ui-refresh.md), решения 3, 4, 5, 14, 16.
Зависимости: нет.

## Результат

В `assets/icons` есть иконки, которые нужны следующим карточкам, и они зарегистрированы
в проверке декодирования ресурсов.

## Границы и контекст

Перед началом прочитать [AGENTS.md](../../../AGENTS.md),
[docs/agent/frontend.md](../../agent/frontend.md) и разделы «Общие правила» и
«Общие проверки» [плана](../ui-refresh.md).

Иконки грузятся компонентом `components/AppIcon.qml` и `AppButton.iconName`
по пути `qrc:/assets/icons/<имя>.svg`. Каталог: `apps/osu-radio-qt/assets/icons/`
(уже есть `LUCIDE-LICENSE` и `REMIX-LICENSE`). Lucide-иконки в каталоге
(`x`, `play`, `shuffle`, `skip-back`, `volume-2`, `gauge`, `layers`, `repeat-2`
и др.) служат образцом формата: 24×24, штрих `currentColor`.

Добавить иконки Lucide (лицензия ISC уже лежит рядом). Сверить актуальные имена
в официальном наборе Lucide, имена ниже ориентировочные: `ellipsis-vertical`
(вертикальные три точки, замена текстового «⋮»), `list-plus`, `grip-vertical`,
`volume-1` (тихая громкость), `volume-x` (без звука), `list-music` (кнопка очереди),
`list-x` (Clear upcoming), `trash-2` (Clear all), `plug` (Integrations), `info` (About).
Оформление файла должно совпадать с существующими Lucide-файлами каталога.

Зарегистрировать каждый новый файл в манифесте проверки декодирования:
`apps/osu-radio-qt/tests/VisualProbe.qml` (случай `native-assets`) и, если нужно,
`apps/osu-radio-qt/tests/test_tools.py`, который сравнивает манифест с каталогом.
Иконки не подключаются к интерфейсу в этой карточке.

## Проверка и приёмка

- `python3 -B -m unittest discover -s apps/osu-radio-qt/tests -p 'test_*.py' -v`
  проходит: манифест совпадает с каталогом.
- `cargo test -p osu-radio-qt --locked -- every_embedded_image_and_font_decodes --test-threads=1`
  проходит и проверяет каждую новую иконку (готовность и размеры).
- Ошибочный случай: удалить запись одной иконки из манифеста временно и убедиться,
  что `test_tools.py` падает; вернуть запись.

## Отчёт о выполнении

Изменённые файлы:

- `apps/osu-radio-qt/assets/icons/`: добавлены 10 иконок Lucide (байт-в-байт из
  официального набора, формат как у существующих): `ellipsis-vertical`, `list-plus`,
  `grip-vertical`, `volume-1`, `volume-x`, `list-music`, `list-x`, `trash`, `plug`, `info`.
- `apps/osu-radio-qt/tests/VisualProbe.qml`: 10 записей в `embeddedAssetSources`.
- `apps/osu-radio-qt/tests/launch_smoke.rs`: ожидаемое число ресурсов 37 → 47.
- `docs/impl/ui-refresh/T13.md`: `trash-2` → `trash` (две ссылки).

Расхождение: в актуальном Lucide `trash-2` — устаревший алиас (`alias.duplicate`),
иконка называется `trash` с той же геометрией. Файл назван `trash.svg`; T13
(Clear all) использует это имя. Остальные имена из карточки совпали с набором.

Проверки:

- `python3 -B -m unittest discover -s apps/osu-radio-qt/tests -p 'test_*.py'`: 20 тестов,
  1 падение: `QmlLintScriptTests.test_newest_generated_module_and_all_qml_files_are_linted_in_registered_paths`
  (порядок путей в аргументах lint). Падает и без правок карточки (проверено
  через `git stash` двух изменённых тестовых файлов), к иконкам не относится.
  `EmbeddedResourceManifestTests` проходит.
- Ошибочный случай: запись `plug.svg` временно удалена из манифеста,
  `test_probe_lists_every_bundled_image_and_font_once` упал с
  `'icons/plug.svg' : new assets need a decode assertion`; запись возвращена.
- `cargo test -p osu-radio-qt --locked --test launch_smoke -- every_embedded_image_and_font_decodes --test-threads=1`:
  ok (47 ресурсов, 0 issues; до правки счётчика тест падал на `37`).

Не проверено: визуальный вид иконок (в интерфейс не подключены, проверка
пользователем в карточках-потребителях); полный набор «Общих проверок» не
запускался (карточка не меняет QML и Rust-код); лицензия Lucide (ISC) уже
лежит в каталоге.
