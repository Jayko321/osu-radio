# T07. Qt: кнопки shuffle и repeat, иконка, галерея

Состояние: выполнено, проверено (Qt offscreen-пробы, qmllint, Clippy); реальный клик в окне — T11.
Источники: [спецификация](../../specs/shuffle-repeat.md), R2, R8;
[решение: Qt](../shuffle-repeat.md#qt-osu-radio-qt). Руководство:
[osu-radio-gui](../../../.agents/skills/osu-radio-gui/SKILL.md).
Зависимости: T05 — `PlayerPresentation.shuffle/repeat/can_change_modes`,
`AppCommand::ToggleShuffle/CycleRepeat`, мок-`Action` режимов.

## Результат

Кнопки в панели плеера работают при соединении, различают состояния иконкой,
акцентом и доступным именем; галерея показывает и переключает режимы офлайн.

## Границы и контекст

- Владение: `apps/osu-radio-qt` ([PlayerPanel.qml](../../../apps/osu-radio-qt/qml/PlayerPanel.qml),
  [qt_view_models.rs](../../../apps/osu-radio-qt/src/qt_view_models.rs),
  [bridge.rs](../../../apps/osu-radio-qt/src/bridge.rs), `qml/Gallery.qml`,
  `assets/icons/`, тесты `tests/`). Клиентские крейты — только читать.
- `PlayerViewModel` (Qt): свойства `shuffle`, `repeatMode` (`"off"`/`"all"`/`"one"`),
  `canChangeModes`; invokable `toggleShuffle()`, `cycleRepeat()`.
- `PlayerPanel.qml`: `shuffleButton`/`repeatButton` сейчас отключены; включить при
  соединении и `canChangeModes`; включённый shuffle и repeat All/One подсвечены
  акцентом (как открытая очередь в заголовке); `repeat-2` для Off/All, новая
  Lucide `repeat-1` для One; доступные имена «Shuffle: off/on», «Repeat:
  off/all/one».
- Отображение режима (иконка/имя/акцент) вынести в общий QML-компонент для
  панели и галереи. Галерея не показывает `PlayerPanel`: подключить кнопки
  к мок-действиям, которые разбираются строками в `bridge.rs`.
- `repeat-1.svg` добавить в ресурсы и в список иконок `tests/VisualProbe.qml`
  (его сверяет `tests/test_tools.py` с файлами `assets/`); обновить список
  в `Gallery.qml` (строка с `repeat-2`).

## Проверка и приёмка

- `tests/AdapterProbe.qml` (около строки 1683) сейчас требует отключённые кнопки:
  заменить проверками включённости при соединении, отключённости без соединения,
  иконки и доступного имени для каждого из состояний (R2) и цикла Off → All →
  One → Off через адаптер;
- проба галереи: переключение обоих режимов офлайн меняет отображение (R8);
- native-assets/VisualProbe-проверка видит `repeat-1.svg`; кнопки режимов не
  перекрываются с соседними (см. проверку `volumeButton`/`shuffleButton`).

Команды Qt offscreen/lint и тестов — из [матрицы](../../agent/development.md#verification-matrix)
и скилла osu-radio-gui; приложение собирается с `LIBCLANG_PATH` при необходимости.
Известные прежние падения (artwork-проба) фиксировать как прежние, не как новые.
Реальный клик в нативном окне — в T11.
