# T06. AppImage с Qt и self-contained helper

Состояние: отложено за пределы первого релиза решением пользователя 2026-10-29.

AppImage и Ubuntu исключены из текущего объёма. Карточка не выполняется и
не блокирует T07–T10; номер сохранён. При возвращении к AppImage нужны новый
план сборки и матрица совместимости: обновлённая T05 выдаёт архив для Arch.

## Исторический план отложенной задачи

Ниже сохранён прежний замысел; его зависимости и критерии сейчас не действуют.
Источники: [спецификация](../../specs/first-release-packaging.md), R4, связанные R5–R6 и R9;
[план](../first-release-packaging.md), этап 3, разделы 4 и 7.
Зависимости: T05 — Rust-бинарники Ubuntu 22.04, закреплённый Qt, иконка,
layout/helper-контракт и сведения о лицензиях; T01 доступна транзитивно.

## Результат

Один x86_64 AppImage содержит GUI, сервер, Qt/QML/plugins и self-contained
helper .NET 10. Комплект работает после переноса/переименования и после
извлечения без FUSE, не требует установленных Qt/.NET/SDK и хранит данные вне образа.

## Границы и контекст

- Добавить AppDir/AppImage средства в `packaging/` на основе результата T05,
  сверив реальные пути по его отчёту. Не пересобирать Rust-приложения отдельно:
  они должны совпадать с Linux-архивом по hash.
- Использовать закреплённые `linuxdeploy` и Qt plugin; точные версии/источники
  и checksums фиксируются до запуска. Передавать исходные
  [QML](../../../apps/osu-radio-qt/qml/Main.qml) для анализа встроенных импортов:
  [build.rs](../../../apps/osu-radio-qt/build.rs) помещает их в resources.
  Проверить X11/Wayland, SVG и фактические native зависимости helper.
- Заменить framework-dependent helper T05 полным self-contained publish
  `linux-x64` по T01. AppRun разрешает пути от себя, сохраняет запуск соседнего
  сервера и helper по T03; app-specific runtime paths не зависят от cwd/mountpoint.
  Desktop entry не должен вызывать установленный на хосте `/usr/bin/osu-radio`.
- Включить PNG/provenance T04, инструкции chmod/запуска/ручной замены/извлечения (включая `libfuse2` на Ubuntu 22.04+),
  фактические системные требования, полные notices по поставляемому Qt/.NET
  и native libraries. Ссылка на исходники Qt и порядок замены DLL/.so — из T05.
  Уточнить затронутые [frontend](../../agent/frontend.md) и
  [development](../../agent/development.md) guides.
- Не менять XDG/QSettings, reset policy, протоколы и desktop UI. Поддержка
  deb/rpm и новые способы хранения данных в объём не входят.

## Проверка и приёмка

1. Сформировать AppDir/AppImage из зафиксированных T05 inputs; проверить hash
   обеих Rust-программ против архива, наличие нужных QML/plugins и лицензий.
   Для добавленных launcher/staging ветвей оставить минимальный self-check,
   ловящий отсутствие обязательного входа и зависимость от cwd.
2. В чистой Ubuntu 22.04 без Qt/.NET/SDK запустить AppImage в native desktop,
   проверить запуск GUI, собственного сервера и реального helper на Realm-фикстуре.
   Повторить из другого cwd после переноса в путь с пробелами/кириллицей
   и переименования; исходники/build tree недоступны.
3. Извлечь содержимое и выполнить AppRun при недоступном FUSE. Ожидается тот же
   запуск, а не зависимость от ранее установленного `osu-radio` или mountpoint.
4. Проверить доступные X11/Wayland-сессии, PNG/desktop metadata и размещение данных вне образа.
   Заменить файл образом той же совместимой сборки и подтвердить сохранение
   созданных данных. Весь OS/import/audio/data lifecycle остаётся T10;
   отсутствие desktop/ОС не записывать как pass по результату headless smoke.

состав runtime/notices, команды и результаты mounted/extracted запусков,
точные ОС/сессии и непроверенные критерии.
